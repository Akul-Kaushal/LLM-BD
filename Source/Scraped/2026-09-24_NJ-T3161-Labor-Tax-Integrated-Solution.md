## Description

RFP for an integrated tax/labor IT solution supporting Unemployment Insurance (UI), Temporary Disability Insurance (TDI), Family Leave Insurance (FLI), Workforce, and Audits functions for the State of New Jersey. Line items span NIGP codes for computer software (208 series), data processing/computer/programming/software services, application service provider (ASP) hosting, mainframe/server application software, cloud computing/hosting, and data conversion services (920 series).

## Relevance

Matches approved keywords "IT Services" and "Information Technology" — the solicitation is issued by NJSTART's "Technology and Telecommunications" category and its priced line items are entirely computer software, application development, hosting, and IT data-processing services (NIGP 208-xx and 920-xx).
